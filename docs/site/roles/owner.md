# Owner

I set the direction, pick each idea's shape in the decide conversation, try every spike and finished feature, and merge into `main` myself after checking it by hand.

## What it does

- Say the seed idea in one paragraph.
- Pick and defend a shape when the lead grills it.
- Try each spike and each approved feature, then run `/taste` so my reaction is saved to `docs/taste.md`.
- Merge from root, run `scripts/sync-worktrees.sh` and `scripts/orch/retire.sh <idea>`.

## What it never does

- Hand a product call to an agent without saying so.
- Merge a feature I haven't tried.

## What it leaves behind

`docs/taste.md`, `docs/rejected.md`, merges on `main`
