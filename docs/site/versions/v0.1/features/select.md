# Select, copy and paste

Moving one note at a time gets slow once a board fills up. Selecting works the way it does in Excalidraw, so it feels familiar.

## How to use it

1. **Select tool:** press **V**.
2. **Box select:** drag across empty board. Every note the box touches is selected.
3. **Add to the selection:** **Shift-click** a note.
4. **Move them together:** drag any selected note. The **arrow keys** nudge the selection.
5. **Copy and paste:** **⌘C / ⌘V** (**Ctrl** on Windows). The copies land next to the originals.

## Good to know

- On another person's board, a selection moves only the notes you're allowed to move.
- While someone is dragging a note, it's locked for everyone else (first to grab it wins), so two people never fight over the same note.
